# AgroConnect (FarmConnect)

A premium marketplace connecting Farmers and Vendors directly.

## Quick Links
- [Project Documentation](AgroConnect_Project_Documentation.md)
- [Frontend (React)](frontend/README.md)
- [Backend (Laravel)](backend/README.md)

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Lucide
- **Backend**: Laravel, MongoDB, Sanctum
- **Features**: Marketplace, Real-time Chat, Smart Market Analytics

## Getting Started
1. **Backend**: `cd backend && composer install && php artisan serve`
2. **Frontend**: `cd frontend && npm install && npm run dev`
